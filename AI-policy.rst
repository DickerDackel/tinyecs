AI Contribution Policy
======================

Please respect, that I don't want any contributions done with the assistance
of AI.  This is a hobby project with focus on the craft of programming.  While
I do use AI to audit code, find typos or inconsistencies between the
documentation and APIs, zero code, documentation, configuratin has been
created by an AI agent.  A hobby project like this is about challenging the
brain, not about getting fast results.

I have no possibility to enforce that request, the simple fact that I ask for
it should be sufficient.
